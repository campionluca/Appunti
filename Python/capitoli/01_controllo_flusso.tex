\chapter{Controllo del Flusso}
\label{chap:controllo-flusso}

\section{Introduzione}
\label{sec:cf-introduzione}
Questo modulo copre le strutture di controllo fondamentali in Python: condizioni, cicli e controllo del flusso dell'esecuzione.

La descrizione mette in evidenza quando preferire costrutti semplici e leggibili, come ridurre la complessità dei rami condizionali e come evitare loop inefficienti. Vedremo pattern comuni (guard clauses, early return) e insidie tipiche (condizioni annidate, off-by-one).

Capire bene il controllo del flusso è essenziale per scrivere codice chiaro, testabile e performante in scenari come elaborazione di liste, validazione di input e automazione di compiti ripetitivi.

\section{Obiettivi di Apprendimento}
\label{sec:cf-obiettivi}
\begin{itemize}
  \item Utilizzare \texttt{if}, \texttt{elif}, \texttt{else} con operatori di confronto e logici.
  \item Scrivere cicli \texttt{for} e \texttt{while}, usare \texttt{break}, \texttt{continue}, \texttt{pass}.
  \item Iterare su sequenze e range in modo idiomatico.
\end{itemize}

\section{Concetti Fondamentali}
\label{sec:cf-concetti}
\begin{tcolorbox}[title=Operatori]
Confronto: \texttt{==}, \texttt{!=}, \texttt{<}, \texttt{>}, \texttt{<=}, \texttt{>=}. Logici: \texttt{and}, \texttt{or}, \texttt{not}. Appartenenza: \texttt{in}, \texttt{not in}.
\end{tcolorbox}

\begin{tcolorbox}[title=Precedenza e short-circuit]
Gli operatori logici valutano da sinistra a destra e possono interrompere la valutazione (\emph{short-circuit}).
Usa parentesi per evitare ambiguità e preferisci condizioni semplici con guard clauses ed \emph{early return} per migliorare leggibilità.
\end{tcolorbox}

\section{Esempi Pratici}
\label{sec:cf-esempi}
\subsection{Condizioni}
\label{subsec:cf-condizioni}
\begin{lstlisting}
eta = 18
if eta < 18:
    print("Minorenne")
elif eta == 18:
    print("Appena maggiorenne")
else:
    print("Maggiorenne")
\end{lstlisting}
\begin{tcolorbox}[title=Spiegazione del codice]
\begin{itemize}
  \item \textbf{Branching (ramificazione)}: Le catene \texttt{if/elif/else} gestiscono casi mutuamente esclusivi. Quando una condizione è vera, Python esegue quel blocco e salta tutti gli altri. Nel nostro esempio, se \texttt{eta < 18}, Python stampa "Minorenne" e ignora \texttt{elif} ed \texttt{else}.
  \item \textbf{Separare logica da output}: Nell'esempio sopra, la stampa è l'effetto collaterale. È meglio separare la decisione (logica) dalla presentazione (I/O). Esempio migliorato:
\end{itemize}
\end{tcolorbox}

\begin{lstlisting}
# Migliore: logica separata dall'output
def classificaEta(eta):
    if eta < 18:
        return "minorenne"
    elif eta == 18:
        return "appenaMaggiorenne"
    else:
        return "maggiorenne"

# La funzione restituisce dati, non stampa
categoria = classificaEta(18)
print(f"Categoria: {categoria}")  # Output gestito separatamente
\end{lstlisting}
\begin{tcolorbox}[title=Perché separare logica da I/O?]
\begin{itemize}
  \item \textbf{Testabilità}: Puoi testare \texttt{classificaEta()} senza dover catturare l'output della console
  \item \textbf{Riusabilità}: La funzione può essere usata sia in un programma console che in un'interfaccia grafica
  \item \textbf{Flessibilità}: Puoi cambiare il formato dell'output senza modificare la logica
\end{itemize}
\end{tcolorbox}

\subsection{Early Return}
\label{subsec:cf-early-return}

\begin{tcolorbox}[
    title=\textbf{Senza early return - Annidamento profondo},
    colback=red!10,
    colframe=red!80!black,
    fonttitle=\bfseries,
    boxrule=1.5pt,
    arc=2mm
]
\begin{lstlisting}
def calcolaSconto(eta, eMembro, importo):
    if eta >= 18:
        if eMembro:
            if importo > 100:
                return importo * 0.2
            else:
                return importo * 0.1
        else:
            return 0
    else:
        return 0

# Utilizzo
print(calcolaSconto(25, True, 150))
# Output: 30.0
\end{lstlisting}
\textbf{Problema:} 3 livelli di annidamento rendono difficile seguire la logica. Devi leggere tutto il codice per capire quando ritorna 0.
\end{tcolorbox}

\vspace{0.3cm}

\begin{tcolorbox}[
    title=\textbf{Con early return (guard clauses)},
    colback=green!10,
    colframe=green!70!black,
    fonttitle=\bfseries,
    boxrule=1.5pt,
    arc=2mm
]
\begin{lstlisting}
def calcolaScontoV2(eta, eMembro, importo):
    if eta < 18:
        return 0
    if not eMembro:
        return 0
    if importo > 100:
        return importo * 0.2
    return importo * 0.1

# Utilizzo
print(calcolaScontoV2(25, True, 150))
# Output: 30.0
\end{lstlisting}
\textbf{Vantaggio:} Logica lineare e chiara. I casi speciali (minorenne, non membro) sono gestiti subito all'inizio con un return immediato. Il codice è più facile da leggere dall'alto verso il basso.
\end{tcolorbox}

\begin{tcolorbox}[title=Guard Clauses]
Le \textbf{guard clauses} sono controlli che escludono subito i casi non validi o speciali, permettendo al codice principale di procedere senza annidamenti. Questo pattern:
\begin{itemize}
  \item Riduce la complessità cognitiva
  \item Rende il codice più manutenibile
  \item Separa chiaramente i casi speciali dalla logica principale
\end{itemize}
\end{tcolorbox}

\subsection{Cicli for e while}
\label{subsec:cf-cicli}

\subsubsection{La funzione range()}
\label{subsubsec:cf-range}
\begin{lstlisting}
# range(stop): genera numeri da 0 a stop-1
for i in range(5):
    print(i)
# Output: 0, 1, 2, 3, 4

# range(start, stop): genera numeri da start a stop-1
for i in range(2, 6):
    print(i)
# Output: 2, 3, 4, 5

# range(start, stop, step): genera numeri con incremento personalizzato
for i in range(0, 10, 2):
    print(i)
# Output: 0, 2, 4, 6, 8

# range con step negativo: contare all'indietro
for i in range(5, 0, -1):
    print(i)
# Output: 5, 4, 3, 2, 1
\end{lstlisting}

\begin{tcolorbox}[title=Come funziona range()]
\texttt{range()} genera una sequenza di numeri interi. Accetta 1, 2 o 3 argomenti:
\begin{itemize}
  \item \texttt{range(stop)}: genera da 0 a stop-1
  \item \texttt{range(start, stop)}: genera da start a stop-1
  \item \texttt{range(start, stop, step)}: genera da start a stop-1, incrementando di step
\end{itemize}
\textbf{Importante}: Il valore \texttt{stop} è sempre escluso dalla sequenza.
\end{tcolorbox}

\subsubsection{enumerate() per collezioni}
\label{subsubsec:cf-enumerate}
\begin{lstlisting}
# Modo sbagliato: usare range() e accedere per indice
nomi = ["Alice", "Bob", "Charlie"]
for i in range(len(nomi)):
    print(f"{i}: {nomi[i]}")

# Modo migliore: usare enumerate()
nomi = ["Alice", "Bob", "Charlie"]
for indice, nome in enumerate(nomi):
    print(f"{indice}: {nome}")

# enumerate() con indice iniziale personalizzato
for num, nome in enumerate(nomi, start=1):
    print(f"{num}. {nome}")
# Output:
# 1. Alice
# 2. Bob
# 3. Charlie
\end{lstlisting}

\begin{tcolorbox}[title=Perché usare enumerate()]
\texttt{enumerate()} è preferibile a \texttt{range(len(...))} perché:
\begin{itemize}
  \item Più leggibile: ottieni direttamente indice e valore
  \item Più sicuro: eviti errori di accesso fuori range
  \item Più Pythonic: segue le convenzioni del linguaggio
\end{itemize}
\end{tcolorbox}

\subsubsection{Ciclo while}
\label{subsubsec:cf-while}
\begin{lstlisting}
# while con condizione
count = 0
while count < 3:
    print(count)
    count += 1
# Output: 0, 1, 2
\end{lstlisting}
\begin{tcolorbox}[title=Quando usare while vs for]
\begin{itemize}
  \item \textbf{for}: quando sai quante iterazioni fare o stai iterando su una collezione
  \item \textbf{while}: quando non sai in anticipo quante iterazioni servono (es: input utente, condizioni complesse)
  \item \textbf{Evita}: \texttt{while True} con break se puoi usare una condizione esplicita
\end{itemize}
\end{tcolorbox}

\subsection{break e continue}
\label{subsec:cf-break-continue}
\begin{lstlisting}
for n in range(10):
    if n == 5:
        break
    if n % 2 == 0:
        continue
    print(n)  # stampa solo dispari prima del 5
\end{lstlisting}
\begin{tcolorbox}[title=Spiegazione del codice]
\begin{itemize}
  \item \textbf{break}: interrompe il ciclo quando `n == 5`; utile per early exit.
  \item \textbf{continue}: salta iterazioni per numeri pari; riduce annidamento.
  \item \textbf{Intento}: il commento esplicita comportamento; preferire condizioni leggibili a logica implicita.
\end{itemize}
\end{tcolorbox}

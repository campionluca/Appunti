\chapter{Stringhe e Formattazione}

\section{Introduzione}
Le stringhe sono sequenze di caratteri immutabili. In Python si manipolano con operatori, metodi e formattazione moderna.

Questa descrizione copre casi d'uso realistici: pulizia dati, normalizzazione, parsing e produzione di messaggi leggibili per log e interfacce. Accenniamo alle problematiche di encoding Unicode, ai separatori locali e alla formattazione numerica e di date.

Saper lavorare bene con le stringhe è centrale in scripting, reportistica, trasformazioni CSV/JSON e interazione con utenti e sistemi.

\section{Obiettivi di Apprendimento}
\begin{itemize}
  \item Usare metodi delle stringhe comuni (strip, split, join, replace).
  \item Formattare output con f-string e format.
  \item Comprendere slicing e manipolazioni di base.
\end{itemize}

\section{Concetti Fondamentali}
\begin{tcolorbox}[title=F-string]
Esempio: \texttt{name = "Ada"; f"Ciao, {name}!"}
\end{tcolorbox}
\begin{tcolorbox}[title=Specifiche di formattazione]
Numeri: \texttt{:.2f} per due decimali, \texttt{:08d} per zero-padding; Testo: \texttt{:<20} allineamento a sinistra, \texttt{:.10} taglio; Date: usa \texttt{datetime.strftime}. Mantieni separata la logica di formattazione dalla logica di calcolo.
\end{tcolorbox}

s = "  Python e' fantastico  "

\end{itemize}

\subsection{Split/Join}
\begin{lstlisting}
frase = "uno,due,tre"
parts = frase.split(",")
joined = ";".join(parts)
print(joined)
\end{lstlisting}
\begin{tcolorbox}[title=Spiegazione del codice]
\begin{itemize}
  \item \textbf{Tokenizzazione}: `split` crea lista di parti; gestire separatori coerenti.
  \item \textbf{Ricombinazione}: `";".join(parts)` unisce con separatore scelto; richiede elementi `str`.
  \item \textbf{CSV semplice}: valido per casi basici; preferire `csv` per casi complessi.
\end{itemize}
\end{tcolorbox}

\subsection{Formattazione}
\begin{lstlisting}
user = "Ada"; score = 99.5
print(f"{user} ha punteggio {score:.1f}")
print("{} ha punteggio {}".format(user, score))
\end{lstlisting}
\begin{tcolorbox}[title=Spiegazione del codice]
\begin{itemize}
  \item \textbf{f-string}: interpolazione con specifiche (`:.1f` per decimali).
  \item \textbf{format}: alternativa compatibile; utile con template riciclati.
  \item \textbf{Separazione}: tenere formattazione vicino all'output, logica separata.
\end{itemize}
\end{tcolorbox}

\section{Approfondimenti}
\begin{tcolorbox}[title=Spiegazioni dettagliate]
Nella scelta tra \textbf{f-string e format}, le f-string dovrebbero essere preferite per la loro leggibilità intrinseca e la capacità di includere espressioni inline. Tuttavia, il metodo \verb|format| resta utile in situazioni con template parametrizzati o formattazioni avanzate riutilizzate.

La gestione di \textbf{precisione e allineamento} è importante per ottenere output formattato correttamente. Specificare formati come \verb|:.2f| per decimali e \verb|:>10| per allineamento a destra permette un controllo fine. Per numeri grandi, l'uso di separatori (come \verb|:,|) migliora la leggibilità.

Quando si trattano testi che dipendono dalla lingua, è fondamentale \textbf{separare le formattazioni} dal codice logico. Evitare concatenazioni manuali di stringhe; preferire template che centralizzano messaggi e formattazioni, facilitando manutenzione e localizzazione.

La \textbf{sanitizzazione dell'input} è critica per evitare injections e comportamenti inattesi. Normalizzare l'input (trim, lowercase) e validare prima di formattare riduce errori e vulnerabilità.

Infine, \textbf{Unicode ed encoding} sono considerazioni essenziali nel moderno sviluppo software. Usare UTF-8 come encoding predefinito è standard; tuttavia, è necessario prestare attenzione alla normalizzazione Unicode (NFC/NFD) quando si confrontano stringhe, poiché rappresentazioni visivamente identiche possono avere byte sequence diverse.
\end{tcolorbox}

\begin{tcolorbox}[title={Per chi viene da C/Java/JS: stringhe, bytes ed encoding}]
\textbf{Stringhe}: sono immutabili e Unicode; operazioni come `replace`, `split`, `join` sono metodi sul tipo `str`.
\textbf{Formattazione}: preferisci f-string (`f"{x:.2f}"`) per chiarezza; `format` utile per template generici.
\textbf{Bytes}: `bytes`/`bytearray` rappresentano dati binari; conversione via `s.encode("utf-8")` e `b.decode("utf-8")`.
\textbf{Regex}: usa `re` per parsing robusto; separa regole dai messaggi di output.

Esempi commentati:
\begin{lstlisting}
# Normalizzazione testo
def normalize(s):
    s = s.strip().lower()
    return " ".join(s.split())  # collassa spazi multipli

# Formattazione numeri
amount = 1234.567
print(f"{amount:,.2f}")  # separatori dipendono dalla locale

# String vs bytes
data = "ciao".encode("utf-8")   # bytes
text = data.decode("utf-8")       # str

# Regex (semplice email)
import re
pat = re.compile(r"^[^@\s]+@[^@\s]+\.[^@\s]+$")
print(bool(pat.match("ada@example.com")))
\end{lstlisting}
\begin{tcolorbox}[title=Spiegazione del codice]
\begin{itemize}
  \item \textbf{Normalizzazione}: trim + lower + collapse spazi per confronti affidabili.
  \item \textbf{Formattazione numeri}: specifiche di locale possono cambiare separatori.
  \item \textbf{Stringhe/bytes}: `encode`/`decode` per confine testo $\rightarrow$ binario.
  \item \textbf{Regex}: pattern minimo per email; preferire librerie se requisiti complessi.
\end{itemize}
\end{tcolorbox}
